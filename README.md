# ivan-ponce.dev

Personal portfolio site for Ivan Ponce — Senior Python Backend Developer.

Built with [Astro](https://astro.build) using the [Ryze](https://github.com/aidrecabrera/ryze) theme by Aidre Cabrera (GPL-3.0).

## Setup

```bash
pnpm install
pnpm dev      # http://localhost:4321
pnpm build    # production build
pnpm preview  # preview production build
```

Requires Node.js >= 22.12.
